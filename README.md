# PhoneLink — দুই ফোনের মধ্যে রিয়েল-টাইম ফরোয়ার্ডিং

একটি মাত্র অ্যাপ দুটি ফোনেই ইনস্টল হয়। প্রতিটি ফোন Sender, Receiver, বা দুটোই হতে পারে।

## ফিচার

**মূল:**
- সব SMS ফরোয়ার্ড (প্রেরকের নাম/নম্বরসহ)
- সব অ্যাপের নোটিফিকেশন ফরোয়ার্ড (WhatsApp, Messenger, Gmail, বিকাশ ইত্যাদি)

**অতিরিক্ত:**
- কল: ইনকামিং বাজছে / মিসড কল / কল শেষ (সময়সহ) / আউটগোয়িং — কন্টাক্ট নামসহ
- ব্যাটারি: কম হলে, চার্জে দিলে/খুললে, ঠিক হলে
- ফোন চালু (রিবুট) হওয়ার খবর + সেই মুহূর্তের ব্যাটারি
- অ্যাপ ইনস্টল / আনইনস্টল
- রিমোট কমান্ড (Receiver ফোন থেকে): 📍 লোকেশন (Google Maps লিংকসহ), 🔋 ব্যাটারি স্ট্যাটাস, 🔔 রিং বাজাও (হারানো ফোন খুঁজতে, ৪৫ সেকেন্ড), 🔕 রিং বন্ধ, 🏓 পিং
- Heartbeat: প্রতি ২৫ মিনিটে Sender নিজে থেকে "অনলাইন আছি" জানায় — Receiver-এ "সর্বশেষ সক্রিয়" দেখা যায়
- অফলাইন কিউ: নেট না থাকলে মেসেজ জমা থাকে (সর্বোচ্চ ৩০০), নেট এলেই পাঠিয়ে দেয়
- ফিল্টার: নির্দিষ্ট অ্যাপ বাদ দেওয়া (প্যাকেজ নাম), ব্লক-শব্দ (সেই শব্দ থাকলে ফরোয়ার্ড হয় না), ডুপ্লিকেট নোটিফিকেশন দমন (৫ সেকেন্ড)
- Receiver ইনবক্স: সর্বোচ্চ ৫০০টি মেসেজ, সার্চ, ট্যাপ করলে কপি, এক ক্লিকে মোছা
- BN UI, ডার্ক থিম

## যেভাবে কাজ করে

মেসেজ যায় একটি পাবলিক রিলে (ডিফল্ট: ntfy.sh — ফ্রি, অ্যাকাউন্ট লাগে না) দিয়ে।
চ্যানেলের নাম পেয়ার কোডের SHA-256 হ্যাশ, তাই কোড ছাড়া কেউ চ্যানেল খুঁজে পাবে না।
নিজের ntfy সার্ভার বসালে অ্যাপে সার্ভার URL বদলে দেওয়া যায়।

দুটি আলাদা চ্যানেল: ডেটা (Sender → Receiver) ও কমান্ড (Receiver → Sender)।

## সেটআপ

1. দুটি ফোনেই APK ইনস্টল করো।
2. প্রথম ফোনে অ্যাপ খোলো — একটা পেয়ার কোড দেখাবে। দ্বিতীয় ফোনে সেই একই কোড লিখে "কোড সেট করো" চাপো।
3. Sender ফোনে: Sender সুইচ অন, Receiver ফোনে: Receiver সুইচ অন। (এক ফোনে দুটোই অন করা যায়।)
4. "সার্ভিস চালু" চাপো — দুই ফোনেই।
5. Sender ফোনে Permission দাও: নোটিফিকেশন Access, SMS/কল/লোকেশন Permission, আর Battery Optimization বন্ধ করো।
6. টেস্ট মেসেজ পাঠিয়ে যাচাই করো।

## সীমাবদ্ধতা

- ইন্টারনেট ছাড়া রিয়েল-টাইম হবে না (কিউতে জমা থাকবে)।
- Android ফোন রিবুট দিলে সার্ভিস নিজে থেকে আবার চালু হয় (BOOT_COMPLETED)।
- কিছু চীনা-ব্র্যান্ড ফোনে (Infinix/Xiaomi ইত্যাদি) Autostart পারমিশন সেটিংস থেকে আলাদা করে অন করতে হতে পারে।
- OTP/ব্যাংক SMS-ও ফরোয়ার্ড হয় — পেয়ার কোড তাই গোপন রাখো।
